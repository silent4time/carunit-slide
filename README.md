# کاریونیت اسلاید (Carunit Slide)

افزونه اسلایدر محصولات ووکامرس برای سایت کاریونیت.

## قابلیت‌ها
- 4 اسلایدر جداگانه
- انتخاب محصولات با ID
- حالت خودکار یا دستی
- جهت حرکت (RTL / LTR)
- سرعت قابل تنظیم

## نصب
فایل‌ها را در پوشه `wp-content/plugins/carunit-slide/` قرار دهید و افزونه را فعال کنید.

## استفاده
شورت‌کد: `[carunit_slide id="1"]` تا `[carunit_slide id="4"]`
